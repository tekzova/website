Questions

Before you ask for it.

Which ships is it for?
Ships that keep an Oil Record Book Part I, and tankers that also keep Part III, and that report bilge and sludge on the EMS 5-1C Excel form.
Does it replace the Oil Record Book?
No. The book remains the official record. ORB Tracker works out the figures and writes each entry in the required wording, so the officer can copy it into the book and check it.
Will it run on the ship’s computer?
It runs on 64-bit Windows 7, 8, 10 and 11. It is one program file: there is nothing to install and no internet is needed.
Where is the data kept?
In one file on the computer, beside the program. Nothing is sent anywhere. Backup copies that file to any folder or USB stick you choose.
Can it start from our existing records?
Yes. Point it at the vessel’s EMS 5-1C workbook and it reads the tank list, capacities, opening ROB and the daily rows already filled in.

A working aid, not a certificate. ORB Tracker prepares figures and wording from what you enter. The officer making the entry remains responsible for checking each one against the ship’s tanks and the flag State’s instructions.
