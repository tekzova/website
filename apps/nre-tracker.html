01 / The problem

The count matters, and nobody keeps it.

Sign-on and sign-off dates end up scattered across a discharge book, a WhatsApp thread and a folder of PDFs. Then the return is due, and it all has to be reconstructed from memory. NRE Tracker is the notebook that should have been kept all along.

A running day count

Enter each sign-on and sign-off once. The total for the financial year is always on the first screen, along with how far you are from the threshold.

Contract and voyage history

Every vessel, every contract, every port date, kept in order and searchable — so the question “when were you last in India?” has an answer.
