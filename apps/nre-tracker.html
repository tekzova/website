The problem

The count matters, and nobody keeps it.

Sign-on and sign-off dates end up scattered across a discharge book, a WhatsApp thread and a folder of PDFs. Then the return is due, and it all has to be reconstructed from memory. NRE Tracker is the notebook that should have been kept all along.

A running day count
