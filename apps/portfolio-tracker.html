01 / Getting your data in

It reads the statements you already get.

You can request a consolidated account statement for your own folios in a couple of minutes, for free. Portfolio Tracker parses that file — every transaction, every folio, every scheme — and builds the portfolio from it. No credentials, no read-only API access, no third party in between.

Password-protected CAS PDFs are handled: you enter the password in the app, the file is opened on the device, and it is never sent anywhere. Statements that overlap are reconciled rather than double-counted — the app spots near-duplicate transactions, asks which folio belongs to whom, and shows an import log of exactly what it added before you commit.

02 / What it works out

Returns done properly, not “current minus invested”.

Money went in on forty different dates. A single percentage is not an answer. So the maths is the maths a fund house would use.

XIRR, three ways

Current for what you still hold, lifetime including everything you have sold, and combined across the whole portfolio. A scheme’s XIRR counts every folio of it — including folios you have fully redeemed, which is where most calculations quietly go wrong.

Cash-flow weighted

Realised and unrealised, kept apart

Gains you have booked and gains still on paper are different questions with different tax consequences. Total invested, total withdrawn, current value, unrealised gain and realised gain each get their own line.

Five distinct numbers

Allocation, three cuts

By asset class, by AMC, and scheme by scheme — so “am I actually diversified or do I own the same twelve companies five times?” has a chart rather than a feeling.

Asset · AMC · Scheme

Growth, against a benchmark

Your portfolio’s value over time, drawn at NAV rather than at cost, with NIFTY on the same axes. The honest version of “am I beating the index?”.

Charted vs NIFTY

Today’s change, with the NAV date on it

Latest NAVs are fetched when you ask for them, and the dashboard always shows which date the valuation is as of — so a stale number is visibly stale instead of quietly wrong.

Refresh NAV

SIPs, detected not typed

The app spots the recurring pattern in your own transactions and proposes the SIP. Registered versus active instalments, monthly or quarterly, and how much of your total arrived that way.

Where it lives

The most sensitive file you own, and it never leaves the room.

A complete picture of what a household is worth is exactly the file that should not be sitting on somebody else’s server. Portfolio Tracker keeps it in the app’s own storage and in a database file you choose the location of. There is no account to open and no copy anywhere else.

Optional passwordTurn it on and the whole database is encrypted on the device, unlocked only by you.
Fully offline modeOne switch stops even the NAV lookup. After that the app makes no network requests at all.

05 / Installing

It installs from a file, not a store.

Portfolio Tracker is not on Google Play yet. You download the APK from this page and install it yourself, which takes about a minute. Android will ask once whether it should allow installs from your browser — that prompt is normal, and you can switch the permission back off afterwards.

Android 7.0 and newer. About 3.2 MB installed. On first run a short wizard sets up your profile, the database file and which modules you want.

  1. Download the APK using the button on this page. Your browser warns that APK files can be harmful — it says that about every file of this type. Tap download anyway.

  2. Open the downloaded file from the notification, or from Files › Downloads.

  3. Allow this one source. Android asks whether your browser or file manager may install apps. Turn it on, install, then turn it back off if you prefer.

  4. Request your CAS and import it. Ask for a consolidated statement for your own folios, save the PDF to the phone, and open Import. The portfolio builds itself from there.

06 / Questions

Before you install.

Do I have to give it my broker or fund login?
No, and there is nowhere to type one. The app works from statement files you download yourself. That is the whole design: if it never has your credentials, they cannot be lost with it.
My CAS PDF is password-protected. Is that a problem?
No. Enter the password when you import and the file is opened on the device. Neither the password nor the file goes anywhere else.
If it is offline, how do the prices update?
Only when you tap Refresh NAV, and only to fetch published net asset values — nothing about your holdings is sent in order to get them. If you would rather it never connected at all, switch on fully offline mode and enter values yourself.
Is this tax advice?
No. The reports arrange your own transaction data into familiar formats, including ITR-style capital gains and Schedule 112A. Checking them, and the return itself, is between you and your accountant.
What happens if I lose the phone?
Whatever your backup says. The app keeps a database file plus the last five recovery points, and you can export a manual backup any time — keep one of them off the phone and a lost device costs you a device, not your records.
Can my wife’s folios live in the same app?
Yes. Separate profiles, separate reports, and a combined family view when you want the household total. At import the app asks which profile a folio belongs to rather than guessing.
Will it start costing money?
Everything on this page is free, with no account and no time limit. If advanced features are added later they will be a one-time purchase, never a subscription. How pricing works.
